# 컴퓨터그래픽스 중간고사 연습퀴즈

## 사용법

### 퀴즈 요청
Claude에게 이렇게 말하면 됩니다:
- "**퀴즈 1 만들어줘**" / "**다음 퀴즈**" / "**새 퀴즈**"

→ Claude가 `quiz_NN/questions.md`와 빈 `answers.md`를 생성합니다.

### 답안 작성
`quiz_NN/answers.md`를 열어서 각 문제 아래에 답을 적습니다.
- 객관식: 번호만 적어도 됨 (예: `②`)
- 주관식: 한글/영어 혼용 OK (Quiz 1 스타일)

### 채점 요청
답안 작성 완료 후 Claude에게:
- "**퀴즈 N 채점해줘**" / "**채점해줘**"

→ Claude가 다음 2개 파일을 생성합니다:
- `quiz_NN/grading.md` — 모범답안 + 평가 + 점수 + 취약점
- `quiz_NN/explanation.md` — 각 개념의 **심화 해설** (배경 이론, 수식, 변형 출제 포인트, 암기 체크리스트)

## 퀴즈 형식 (한 세트당)
- **10문제 / 15점 만점** (중간고사 예상 형식)
- 객관식 4문제 (각 1점 = 4점)
- 단답형 3문제 (각 1점 = 3점)
- 서술형 3문제 (각 2~3점 = 8점)
- 범위: 1장(Introduction) ~ 6장(Texturing)

## 폴더 구조
```
연습문제/
├── README.md           ← 이 파일
├── quiz_01/
│   ├── questions.md     ← 문제
│   ├── answers.md       ← 네가 답 쓰는 곳
│   ├── grading.md       ← 채점 결과 (채점 요청 시 생성)
│   └── explanation.md   ← 심화 해설 (채점 요청 시 생성)
├── quiz_02/
└── ...
```
